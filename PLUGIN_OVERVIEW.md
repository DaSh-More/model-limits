# Model Limits

Все лимиты и балансы ваших моделей в одном месте.

- Остатки окон Claude Code, Kimi Code и других провайдеров со всех устройств BB.
- Балансы DeepSeek и Polza; любой HTTP-сервис добавляется в настройках без релиза.
- Один аккаунт на нескольких устройствах объединяется в одну строку.
- Шапка чата: модель открытого чата, использованный процент и его лимит с цветовой индикацией.
- Команда `bb model-limits` для снимка в терминале и в JSON.

Ключи хранятся в секретных полях настроек и не попадают в браузер, логи и вывод CLI.
